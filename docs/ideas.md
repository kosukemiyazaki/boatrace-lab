- 新しいアイデアは、**実行する前に**この表に「仮説・試す組み合わせ・判定基準」を書いてコミットする。
- 試す組み合わせは書いたものだけ。後から増やす場合は、別のアイデアとして書き足してからコミットする。
- 実行後は、**試した組み合わせすべての結果**を「結果」に書き足す（一番良いものだけを書かない）。
- 判定基準は、実行前に書いたものから変えない。
- テスト期間（2026-09-01〜10-04）と前向きテストの期間は、事前に決めた判定以外では使わない。

## IDEA-009 締切時オッズで買えたとしたらの上限（3連単EV戦略に見込みがあるか）
- 登録日：2026-10-11　状態：**実施済み（2026-10-11）**
- 目的：撤退判定（約2,000レースの6分前オッズ）を待たずに、3連単のEV戦略に見込みがあるかを開発期間のデータだけで確かめる。
- 考え方：実際に買えるのは締切6分前のオッズで、締切時のオッズは6分前より情報が多い（締切直前の資金が入っている）。
  そこで「締切時オッズを見てから、締切時オッズで買えた」という**実際より有利な前提**でバックテストし、その回収率を**上限**とみなす。
  上限でも届かなければ、6分前オッズで買う実際の戦略も届かない。
- 予測：直前情報・節間成績入り（撤退判定のモデルと同じ特徴量 `FEATS_C1`）の段階別 LightGBM → 3連単確率 → Isotonic 校正。
  四半期ごとに学習し直すウォークフォワード（Step 2 と同じ分け方：学習 〜s-3か月末 / 早期終了 s-2か月 / 校正 s-1か月 / 評価 s〜s+2か月）。
  評価は 2026-01〜2026-08（直前情報が 2025-10 以降しかないため、2026Q1〜Q3）。テスト期間（2026-09以降）は使わない。
- 市場との組み合わせ：π ∝ P_model^a × P_締切時^b。a, b は各四半期の校正月で推定（評価期間は使わない）。
- 買い方（Step 2 と同じ9通りのみ）：オッズ上限 {30,50,100倍} × EV閾値 {1.1,1.2,1.3}。π×締切時オッズ > 閾値の組番を EV の高い順に最大10点・各100円（1レース上限1000円）。
  払戻は公式の払戻金（F/L/欠場艇を含む組番は返還）。
- さらに有利に出る点（上限として扱う理由）：締切時オッズを見て買える、自分の賭けでオッズが下がらない、9通りの最も良いものを見る。
- 判定基準：
  - 9通りすべての回収率（点推定）が100%未満 → **上限でも届かない**。6分前オッズでの3連単EV戦略に見込みはないと判断する（撤退判定は登録どおり行うが、結果の見込みはこれで分かる）。
  - どれかが110%以上で、95%信頼区間（日単位）の下限が100%を超える → 上限では届く。撤退判定を待つ意味がある。
  - それ以外 → はっきりしない。撤退判定を待つ。
  - 参考として、モデル単体・締切時の市場・組み合わせの3連単対数損失も記録する。
- スクリプト：`scripts/exp_idea009.py`
- 結果（2026-10-11 実行、`results/idea009/idea009.md`。評価 2026-01〜08、37,573レース・243日）：
  - 3連単対数損失：モデル単体 3.7777 / 締切時の市場 3.6916 / 組み合わせ 3.6868。**モデルを足しても締切時の市場より 0.005 しか良くならない**（四半期ごとに 0.006・0.006・0.002）。
    組み合わせの重みは市場 0.80〜0.84、モデル 0.23〜0.27。
  - 買い方9通り（全件）：EV閾値1.1でも買える組番は1日0.4〜1.2点しかなく、回収率は 34%・58%・68%（オッズ上限 30・50・100倍）。
    閾値1.2では1日0.05〜0.14点（12〜34点・的中1〜2本）で、回収率 108%・220%・136% だが信頼区間は 0〜520% と、件数が少なすぎて何も言えない。閾値1.3はほぼ0点。
  - **判定（登録した基準どおり）：はっきりしない**（9通りすべてが100%未満ではないが、110%以上かつ信頼区間の下限が100%超のものもない）。

## IDEA-010 市場の値付けの偏りを直接測る（3連単、締切時オッズ、開発期間のみ）

    それも控除25%を埋めるには足りない。3連単で結果を出すには、この地図の上でさらに「同じオッズ帯の中で当たりやすい目を分ける」情報が必要。
