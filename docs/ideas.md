## 運用ルール
- 新しいアイデアは、**実行する前に**この表に「仮説・試す組み合わせ・判定基準」を書いてコミットする。
- 試す組み合わせは書いたものだけ。後から増やす場合は、別のアイデアとして書き足してからコミットする。
- 実行後は、**試した組み合わせすべての結果**を「結果」に書き足す（一番良いものだけを書かない）。
- 判定基準は、実行前に書いたものから変えない。
- テスト期間（2026-09-01〜10-04）と前向きテストの期間は、事前に決めた判定以外では使わない。

  - **判定：4条件とも不採用**（信頼区間の下限が100%を大きく下回る）。荒れやすい条件では大穴の回収率が全体より少し高いが、控除と大穴の過剰人気を埋めるにはほど遠い。


## IDEA-008 楽しみで買う人のお金が多いレースほど、勝てるずれが残る
- 登録日：2026-10-08　状態：**登録のみ**（まだ実行しない）
- 仮説：普段買わない人や、推しで買う人のお金が多いレースでは、人気が実力以上に買われ、市場の確率がずれる。
- 対象の分け方（事前に固定）：
  1. レースの格：SG / G1 / G2 / G3 / 一般
  2. 注目度：優勝戦・ドリーム戦 / それ以外
  3. 選手属性：女子戦 / 地元選手が出走 / その他
- 必要データ：番組表（格・レース名・選手の登録地）、締切時オッズ、払戻（取得済みのものでまず確認）
- 測るもの：
  - 各区分で「人気順位別の回収率」と「市場の確率と実際の当たり率のずれ」
  - 区分ごとのレース数と売上（自分の賭けでどれだけオッズが下がるか）
- 判定基準：どれかの区分で、人気帯ごとの回収率が他の区分より明確に高く（日単位ブートストラップの95%区間が重ならない）、かつ100%に近い帯がある場合のみ、モデルでの検証に進む。
- 注意：区分の数（3種類・計9区分程度）を記録し、偶然の当たりを割り引いて判断する。テスト期間（2026-09以降）は使わない。
- 必要データの取得可否（登録時点の見込み。実行前に確認する）：
  - レース名（優勝戦・ドリーム戦など）：番組表・競走成績に**あり**（取得済み）。
  - レースの格（SG / G1 / G2 / G3 / 一般）：番組表に格の項目はなく、開催名（タイトル）から判定するか、boatrace.jp のグレード別日程ページから取る必要がある。
  - 女子戦：番組表に性別の項目はない。開催名（オールレディース・ヴィーナスシリーズなど）から判定する見込み。
  - 地元選手：番組表の支部と、場の所在地（都道府県）の対応表で判定できる見込み。
  - 売上：**レース別の売上は公式ページから取れない**（IDEA-005 で確認済み）。自分の賭けでオッズがどれだけ下がるかは、売上がないと直接は出せないので、代わりの指標（オッズの逆数の合計など）を検討する必要がある。
  - 締切時オッズ・払戻：取得済み（2025-10〜2026-08 が揃っている）。
