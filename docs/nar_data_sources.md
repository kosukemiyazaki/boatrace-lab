## CSV の主な項目（説明書より）
- **レース一覧**：競馬場、競走年月日、レース番号、発走時刻、競走種類名称、レース名、芝ダート区分、回り、距離、天候、馬場、頭数、条件、1〜5着賞金、上がり4F・3F、ハロンタイム（最大15）、コーナー通過順（最大8）
- **出馬表**：競馬場、競走年月日、レース番号、枠番、馬番、馬名、性、齢、毛色、生年月日、父・母・母父、騎手名・所属、負担重量、騎手成績、調教師・所属、馬主、生産牧場、馬体重・増減、全成績、ダート左右別成績、当競馬場成績、当距離成績、最高タイム、着順、タイム、着差、上がり3F、人気
- **払戻金**：単勝・複勝・枠複・枠単・馬複・馬単・ワイド・（3連複・3連単）の組番・払戻金・人気
- **オッズ**：競馬場、競走年月日、レース番号、賭式（3連単など）、番号1〜3、オッズ、オッズ（最大）、人気
- 競走馬・騎手・調教師を一意に特定するIDは**提供されていない**（説明書のFAQ）。名前と生年月日などで照合する必要がある。

## 利用上の注意（説明書より）
- 推奨される取得頻度：当日ファイルは**2分に1回程度**、月次ファイルは**1日に1回を上限**。異常な件数のアクセスはIPアドレス単位で遮断されることがある。
- データ仕様は予告なく変わることがある。
- 利用規約（`https://www.keiba.go.jp/terms.html`、2026-10-08 に確認）：
  - 著作権：掲載内容の権利は地方競馬全国協会・各主催者などに帰属し、**事前の許諾なく転載・複製することを禁じる**。
  - 不正アクセス：異常な件数のアクセスは IP アドレス単位で遮断することがある。
  - データダウンロード機能を個人の分析に使うこと自体を禁じる記載はない。ただし**取得したデータの再配布（公開リポジトリへの保存を含む）は許諾が必要**と読むのが安全。
  - 収集を実装する場合は、データを公開リポジトリに置かない（private な保存先を用意する）こと、取得頻度を説明書の推奨以下にすることが前提。

## ボートレースとの比較
| | ボートレース（現状） | 地方競馬 |
|---|---|---|
| 出走表・成績の過去分 | 公式LZH（2023-10〜取得済み） | 公式CSV（1998-01〜） |
| 過去の確定オッズ | 1レース1ページ（約9秒/件）で取得 | CSVで一括（2026-03〜のみ） |
| 締切前のオッズ | 自前で締切15/10/6分前に取得（`live`） | 公式の当日ファイルに中間オッズあり（2分ごと） |
| 取得の手間 | 大（1レースごと） | 小（月・日単位のZIP） |

過去の確定オッズは 2026-03 以降の約7か月分しかないため、オッズを使う検証の開発期間は短くなる。
出馬表・成績は長期間あるので、着順予測モデルの学習データは十分にある。
