## 結論
- どちらのモデルも、テスト期間で回収率100%を有意に超えなかった（信頼区間が100%をまたぎ、点推定は控除後の水準）。
- 確率の校正は全体では取れている（予測と実際がほぼ一致）。ただし「EVが大きい目」に絞ると
  モデルの予測的中数は実際の2〜3倍で、選別によって過大評価の目が拾われている。実際の的中は市場の予測に近い。
- 選択期間で LightGBM は回収率134.6%だったが、テストでは79.3%で再現しなかった（30的中の高配当頼み＝偶然）。
